# Семантика языка clvr

## Типы данных
В нашем языке используется статическая типизация (фиксируется при объявлении).  
Бинарные операции возможны только между операндами одного типа.  
Поддерживаются следующие типы:

- int: 32-битное целое число. Особенности:
    - Поддерживает арифметические операции: + - * / %
    - Деление / — целочисленное.
    - % возможен.
    - Деление на 0 — ошибка времени выполнения.
- float: вещественный тип данных. 64-битный IEEE‑754 (double precision). Особенности:
    - ~15–16 значащих цифр точности.
    - Поддерживает арифметические операции: + - * /
    - Деление / — целочисленное.
    - % не возможен.
    - Деление на 0 — ошибка времени выполнения.
- string: строковый тип данных. Особенности:
    - Заключается в двойные кавычки "".
    - Поддерживает операции: конкатенация (`+`), измерение длины (`len()`), декомпозиция (доступ по индексу `[]`).
    - Является последовательностью Unicode-символов.
    - Поддерживается ввод (`input`) и вывод (`output`) строк.
    - Поддерживает escape-последовательности для ввода специальных символов внутри строкового литерала.
- bool: булев тип данных. 
    - Литералы: `true` и `false`.  
    - Поддерживает только операции сравнения (см. ниже) и использование в условии `if`.  
    - Не может использоваться в арифметических операциях (`+`, `-`, `*`, `/`, `%`).  
    - Неявные преобразования в другие типы отсутствуют.


## Точка входа
Точкой входа в программу является "int main()".

## Область видимости
1. Лексическая область видимости: переменные локальны в пределах блока []. В блоке можно захватывать переменные внешнего блока и глобальные.

## Ввод и вывод

Ввод (input):
- Для каждого идентификатора читается значение.
- Тип вводимого значения должен соответствовать типу переменной.
  - int: ожидается строка, представляющая целое число в десятичной системе (допускается знак + или -).
  - float: ожидается строка, представляющая вещественное число в десятичной форме (допускается знак + или -).
  - string: считывается вся строка целиком (до перевода строки).
  - bool: ожидается строка "true" или "false" (регистронезависимо) — преобразуется в соответствующее булево значение. 
- Переменная должна быть объявлена.
- При неправильном вводе возникает ошибка времени выполнения.

Вывод (output):
- Вычисляет выражения слева направо.
- Выводит их представление.
- Разрешены все базовые типы и литералы.  
  Для bool выводится "true" или "false". 

## Ошибка ввода

| Тип переменной | Неверный ввод                                 |
|----------------|-----------------------------------------------|
| int          | Дробное число, строка                         |
| float        | Строка                                        |
| string       | Отсутствует закрывающая кавычка               |
| bool         | Любая строка, кроме "true"/"false" (и их вариантов с разным регистром) |
